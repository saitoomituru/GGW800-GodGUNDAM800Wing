# 実験票とログ

[統合実験 #3](https://github.com/saitoomituru/GGW800-GodGUNDAM800Wing/issues/3) / [設計](../docs/design.ja.md)

各実験を1 directoryにまとめる。実験票、対象設計commit、負荷条件、素子両面・電池・室内外温度、発電端と電池端のV/I/W/Wh、補機消費、灯油消費、雪・融解・排水状態、機器と校正条件、raw data、解析条件、失敗・変更点を記録する。

simulation／bench測定／現地運用を区別する。補給量・室温維持・作業負担との比較から採用条件を更新する。未取得欄はunknownでよく、記録作業や計測器を追加自弁の義務にしない。

公開できる測定結果・根拠のある失敗も成果として保存する。秘密・私的資料・無関係な個人情報は含めない。現在、実験結果は未収録。
