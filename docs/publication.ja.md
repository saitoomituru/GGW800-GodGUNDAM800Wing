# CAD・SPICE公開仕様

状態: 公開形式の設計。実CAD・回路・SPICEモデルは未作成。型番・寸法・定数は現物または根拠資料を得た枝から追加する。

## 公開単位

| 対象 | 編集可能な正本 | 併せて公開する情報 |
| --- | --- | --- |
| 受熱板・締結・取付 | 使用CADのnative project、またはparametric source | STEP等の中立形式、寸法図、単位、材質、表面・接触条件、公差 |
| 雪ヒートジャケット | CAD原本と配管・熱経路 | 容積・配管径・接続、排水・凍結・着脱、直接／二次ループの別 |
| 回路 | 編集可能な回路source。形式は採用ツールと共に記録 | 閲覧用PDF/SVG、netlist、BOM対応、結線・測定点 |
| SPICE | テキストnetlist（例: .cir / .sp）、必要なmodel / subcircuit | simulator・版・方言、実行コマンド、掃引・初期値・境界条件、波形CSV・ログ |
| 部材 | BOM台帳 | part ID、型番、数量、代替条件、出典、入手・加工状態 |
| 実験 | 実験票とraw data | 対象revision、機器、校正・条件、結果、失敗、解析方法 |

CADは使用ツールを今固定しない。native原本とSTEP等を組にし、STLや画像だけを唯一の設計原本にしない。mesh exportは製作補助として追加できる。

SPICEはngspice互換のテキストnetlistを第一候補とする。LTspice等の固有機能を採用する場合は方言・版・依存を明記し、未確認の互換性を表示しない。回路図エディタは未選定。

## 熱電モデル・充電系

素子のSeebeck係数、内部抵抗、熱抵抗等は、測定／メーカー資料／仮定のどれかと温度範囲・単位を付ける。電気等価モデルを熱・機構全体の実証へ拡張しない。未知の値はunknownとして残し、動く波形を得るために実測値を捏造しない。

約980Whからセル数・電圧を逆算しない。DC/DC、起動、負荷追従、逆流、充電条件、BMS、補機消費は現物選定後にモデル・結線へ反映する。SPICEは装置制御も実機充電の承認もしない。

## 記録と配布

各公開単位に、設計ID、日付、revision、担当／出典、対象Issue、license、設計／simulation／built／measuredの状態、必要ツールと版を添える。独自の版数座標は今制定せず、当面Git commitをrevisionに使う。

hardware配下のCAD・回路・SPICE設計SourceはCERN-OHL-P-2.0。third-party modelは出典のlicenseを保持し、再配布不可なら同梱せず取得先・利用者側の準備条件を示す。画像・名称の参照から第三者CADやキャラクター素材の利用権を推定しない。

大容量配布が必要になった時点でGit LFS／Release等を検討し、支払・容量資源があると仮定しない。採用済みの測定CSV・SPICEテキスト・再現票は可能な範囲でGitへ残す。生成しただけの波形や空placeholderを測定成果として扱わない。
