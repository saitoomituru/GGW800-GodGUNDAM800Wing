新repository側の技術課題を進めても越冬完了・研究復旧を宣言しない。既存Issueを勝手に完了扱いせず、技術成果を上位窓口へ返す。

固定queueではなく、各Issueの資源・依存条件で起動する。CADの完成をSPICE着手の必須条件にせず、スターリングの候補も消さない。新しい実機測定は本repositoryへ残し、必要な要約をManifestへ接続する。
